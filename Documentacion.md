1. JAVA INICIO
   EN ESTE APARTAD NOS DA UNA BREVE EXPLICACION DE COMO FUNCIONA JAVA CON UN 
   "HELLO WORD" PARA EMPEZAR A APPRENDER EN ESTE

public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

2. INTRODUCCUION JAVA
   EN ESTE APARTADO NO ENSEÑA A COMO PRESENTAR UN NOMBRE YA INGRESADO POR PANTALLA,
   TAMBIEN NOS EXPLICA COMO E USA JAVA Y PARA QUE SIRVE

public class Main {
  public static void main(String[] args) {
    String name = "John";
    System.out.println("Hello " + name);
  }
}

3. JAVA PPRIMEROS PASOS
   EN ESTE APARTADO NO MUESTRA UN PASO A PASO DE COMO INSTALAR LA APP Y TAMBIEN NOS DA UNA INTRODUCCION 
   RAPIDA SE COMO EMPEZAR A ESCRIBIR UN CODIGO

public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

4. SINTAXIS
   JAVA EXIGE QUE EL CÓDIGO ESTÉ DENTRO DE UNA CLASE CUYO NOMBRE COINCIDA CON EL ARCHIVO (MAIN.JAVA). EL PROGRAMA INICIA EN EL MÉTODO MAIN, USA SYSTEM.OUT.PRINTLN() PARA MOSTRAR TEXTO Y CADA INSTRUCCIÓN TERMINA CON PUNTO Y COMA (;).

public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

5. DECLARACIONES
   UN PROGRAMA DE JAVA ES UNA LISTA DE SENTENCIAS QUE SE EJECUTAN EN ORDEN Y DEBEN TERMINAR SIEMPRE CON UN PUNTO Y COMA.

System.out.println("Hello World!");
System.out.println("Have a good day!");
System.out.println("Learning Java is fun!");

6. DESAFIOS DEL CODIGO
  PARA RESOLVER ESTE RETO, DEBEMOS ESCRIBIR LA SENTENCIA System.out.println("¡Hola, Java!"); DENTRO DEL MÉTODO main(), ASEGURANDONOS DE AGRAGAR EL PUNTO Y COMA PARA 
  QUE EL COMPILADOR NO ARROJE ERROR

public class Main {
  public static void main(String[] args) {
    System.out.println("Hello, Java!");
  }
}

7. IMPRIMIR TEXTO
   PARA IMPRIMIR TEXTO EN JAVA SE UTILIZA EL MÉTODO System.out.println(), CADA INSTRUCCIÓN AGREGA UNA NUEVA LÍNEA Y EL TEXTO DEBE ESTAR SIEMPRE ENTRE COMILLAS DOBLES PARA EVITAR ERRORES DE SINTAXIS.

   System.out.println("Hello World!");
   System.out.println("I am learning Java.");
   System.out.println("It is awesome!");

8. IMPRIMIR NUMEROS 
   PARA IMPRIMIR NÚMEROS EN JAVA NO SE USAN COMILLAS DOBLES Y SE PUEDEN REALIZAR CÁLCULOS MATEMÁTICOS DIRECTAMENTE DENTRO DEL MÉTODO. LAS RESPUESTAS DE LOS EJEMPLOS SON:
       3
       358
        50000
        3 + 3 = 6
        2 * 5 = 10

        System.out.println(3);
    System.out.println(358);

    System.out.println(3 + 3);

9. COMENTARIOS DE JAVA 
    Los comentarios pueden utilizarse para explicar el código Java y hacerlo más legible. También pueden usarse para impedir la ejecución al probar código alternativo.
    Los comentarios de una sola línea comienzan con dos barras inclinadas ( //).

    Cualquier texto que se encuentre entre //y el final de la línea es ignorado por Java (no se ejecutará).

    // This is a comment
    System.out.println("Hello World");
    System.out.println("Hello World"); // This is a comment
